GERADOR DE RELIANS V4.4

NOVIDADES DE CAPTURA
- Cada Relian possui categoria: Comum, Incomum, Raro, Lendário ou Lendário Especial.
- A taxa base sugerida é 40%, 30%, 20%, 5% ou 1%, mas pode ser alterada no editor.
- A ficha possui calculadora e rolagem 1d100 de captura.
- Datacubos, porcentagem atual de HP, status negativo e afinidade modificam a chance.
- A afinidade vai de 0,0 a 5,0 e pode ser ajustada diretamente na ficha.
- Resultado 1 é captura crítica; 100 é falha crítica, exceto com 100% de chance.

PASTAS VINCULADAS
Vincule a pasta raiz pelo botão “Vincular pasta-base”. Depois disso:
- Novo Relian: cria Pasta_Relians/Nome do Relian/relian.json
- Novo movimento: cria Movimentos/id.json
- Nova região: cria Regioes/id.json
- Novo bioma: cria Biomas/id.json
- Regras: cria config/regras.json

A pasta é sincronizada automaticamente enquanto a página estiver aberta. Alterações manuais nos JSON entram no site na próxima sincronização. O Chrome ou Edge pode pedir autorização novamente após reiniciar.


ALTERAÇÕES DESTA VERSÃO
- Traços são sorteados automaticamente entre todos os JSON da pasta Tracos.
- O cadastro de Relian não exige mais IDs de traços.
- Movimentos usam o formato nivel=movimento, por exemplo: 1=golpear.
- O formato antigo nivel|movimento ainda é aceito ao carregar dados antigos.
